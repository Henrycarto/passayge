# Security

Passayge is a sandbox with synthetic data. It is not connected to ELGA, the e-card system or any real service, and it must never hold real patient data.

## Reporting a problem

Please report security problems privately, not in a public issue:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability** and describe what you found and how to reproduce it.

Only the maintainer sees the report. You will get an answer within a week.

Worth reporting: any way to make the sandbox send a request outside itself, any way real personal data could end up in the repository or in a request, and any flaw in how the gateway enforces the access rules.
